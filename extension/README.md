# Voice Clip Recorder

Простое Firefox-расширение для записи коротких голосовых клипов.

## Возможности

- Запись микрофона.
- Запись звука вкладки, окна или экрана, если Firefox и выбранный источник отдают аудиодорожку.
- Выбор открытой вкладки из списка перед запуском записи.
- Предпросмотр выбранной вкладки, окна или экрана перед записью.
- Тестирование микрофона и звука вкладки через live-метры уровня.
- Быстрое открытие рекордера из кнопки расширения в углу браузера.
- Отдельная кнопка `Открыть отдельно` для полноразмерной вкладки, если popup мешает длинной записи.
- Оформление адаптируется под светлую или темную тему браузера.
- Смешивание микрофона и звука вкладки в одну аудиодорожку.
- Опциональная запись видео выбранной вкладки, окна или экрана.
- Основной упор на аудио: `OGG Opus`, `OGG audio`, `WebM Opus`, `WebM audio`, `WAV PCM`.
- Нативные `MP3`, `M4A/AAC`, `AAC` и `FLAC` появляются в списке только если текущий Firefox поддерживает такой `MediaRecorder`-формат.
- Видео экспортируется отдельно в `WebM video`, когда включена опция видео.

## Установка для проверки

1. Откройте `about:debugging#/runtime/this-firefox`.
2. Нажмите `Load Temporary Add-on` / `Загрузить временное дополнение`.
3. Выберите `manifest.json` из этой папки.
4. Нажмите на иконку расширения, чтобы открыть маленькое окно рекордера прямо из панели Firefox.

Если до этого была загружена старая версия, удалите ее из `about:debugging` и загрузите `manifest.json` заново. Для Firefox в манифесте используется `background.scripts`, потому что `background.service_worker` может быть отключен.

## Как записывать

1. Выберите источники: микрофон, вкладка/экран, видео.
2. Нажмите `Проверить источники`.
3. Проверьте предпросмотр и уровни звука.
4. Нажмите `Записать`; запись пойдет с уже проверенного потока.
5. Нажмите `Стоп`, затем скачайте файл.

Кнопка `Перейти` рядом со списком вкладок только вручную активирует выбранную вкладку для сверки. Сам запрос захвата остается в окне рекордера, иначе Firefox может потерять пользовательское действие и не показать диалог выбора источника.

В полноразмерной вкладке кнопка `Открыть отдельно` скрывается. Светлая и темная цветовые схемы переключаются через `prefers-color-scheme`, который Firefox передает страницам расширений от темы браузера.

## Сборка XPI

Из папки расширения:

```powershell
Compress-Archive -Path .\manifest.json,.\background.js,.\recorder,.\icons -DestinationPath .\voice-clip-recorder-v1.0.0-firefox.zip -Force
Move-Item .\voice-clip-recorder-v1.0.0-firefox.zip .\voice-clip-recorder-v1.0.0-firefox.xpi -Force
```

Для постоянной установки в обычный Firefox пакет нужно подписать через addons.mozilla.org.

## Важные ограничения Firefox

- Микрофон запрашивается напрямую через разрешение браузера.
- Список вкладок в расширении нужен, чтобы выбрать ориентир перед записью. Firefox все равно показывает свой диалог выбора источника, где нужно подтвердить конкретную вкладку, окно или экран.
- Звук вкладки, окна или системы идет через `getDisplayMedia`. Если Firefox не отдаст аудиодорожку для выбранного источника, расширение покажет предупреждение и запишет только доступные дорожки.
- Firefox специально спрашивает разрешение на захват вкладки, окна или экрана при каждом новом вызове `getDisplayMedia`. Расширение не может сохранить это разрешение навсегда, но после `Проверить источники` запись идет с уже открытого потока без повторного запроса, пока не нажать `Сбросить` или пока источник не остановлен.
- `MP3` нельзя получить простым переименованием файла: браузер должен уметь кодировать `audio/mpeg`, либо нужен отдельный MP3-кодировщик. Поэтому расширение показывает MP3 только при нативной поддержке Firefox.
- `WAV PCM` создается локальной конвертацией после записи; для длинных записей файл будет заметно больше, чем `OGG Opus`.
- Для Telegram обычно лучше выбирать `OGG Opus (.ogg)`. Расширение может подготовить файл, но не может заставить Telegram Web отправить его именно как нативную голосовую заметку.
