# Voice Clip Recorder

Firefox-расширение-пульт для локального помощника Voice Clip Recorder.

## Возможности

- Всегда работает через Native Messaging helper.
- Старт, стоп, пауза и продолжение записи.
- Отложенный старт и авто-пауза после старта.
- Новый UI в стиле установщика helper.
- Открытие папки с последним файлом из интерфейса.

## Установка для проверки

1. Откройте `about:debugging#/runtime/this-firefox`.
2. Нажмите `Load Temporary Add-on` / `Загрузить временное дополнение`.
3. Выберите `manifest.json` из этой папки.
4. Установите helper из релиза репозитория и полностью перезапустите Firefox.
5. Нажмите на иконку расширения, чтобы открыть страницу управления записью.

Если до этого была загружена старая версия, удалите её из `about:debugging` и загрузите `manifest.json` заново. Для Firefox в манифесте используется `background.scripts`, потому что `background.service_worker` может быть отключен.

## Как записывать

1. Откройте страницу расширения кнопкой в Firefox.
2. При необходимости задайте `Отложенный старт` и `Авто-паузу после старта`.
3. Нажмите `Старт`.
4. Используйте `Пауза` / `Продолжить` по мере необходимости.
5. Нажмите `Стоп`, затем `Открыть папку`.

## Сборка XPI

```powershell
powershell -ExecutionPolicy Bypass -File .\build-xpi.ps1
```

Для постоянной установки в обычный Firefox пакет нужно подписать через addons.mozilla.org.

## Важные замечания

- Расширение само больше не захватывает медиа через `MediaRecorder`; этим занимается локальный helper.
- Если helper не установлен или Firefox не был перезапущен после установки, страница покажет блок со ссылкой на установщик.
- При закрытии страницы во время записи расширение отправляет `cancel`, чтобы не оставлять частичный файл.
